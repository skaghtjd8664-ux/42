# push_swap

---

## Description
이 프로젝트는 두 개의 스택(`stack_a`, `stack_b`)과 제한된 명령어 집합을 사용하여 주어진 정수 배열을 오름차순으로 정렬하는 프로그램입니다. 입력된 난수의 정렬 상태(무질서도)를 계산하여 데이터의 상태에 따라 `--simple`, `--medium`, `--complex`, `--adaptive` 정렬 전략을 유동적으로 채택하는 기능을 포함하고 있습니다.
